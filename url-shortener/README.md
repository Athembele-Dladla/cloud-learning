# 🔗 URL Shortener

A serverless URL shortener built with Netlify Functions and Supabase (PostgreSQL).

## 🚀 Live Site
👉 [Try it here](https://athembele-url-shortener.netlify.app)

## 🛠️ Tech Used
- HTML, CSS, JavaScript (frontend)
- Netlify Functions (serverless backend)
- Supabase (PostgreSQL database)

## ☁️ Cloud Concepts Learned
> Serverless functions, cloud databases, environment variables, and HTTP redirects.

## How It Works
1. Paste a long URL into the input
2. Click Shorten — a short code is generated and saved to Supabase
3. Visit the short URL → get redirected to the original
