# ☁️ File Upload App

A cloud file upload application that lets users upload files directly to Cloudinary storage via a serverless function.

## 🚀 Live Site
👉 [View it here](https://athembele-file-upload-app.netlify.app)

## 🔑 Access Code
`WTC-T8ENJDT7`

## 🛠️ Tech Used
- HTML, CSS, JavaScript (frontend)
- Netlify Functions (serverless backend)
- Cloudinary (cloud file storage)

## ✨ Features
- 📁 Drag & drop file upload
- 🖼️ Image preview after upload
- 📋 Copy file URL to clipboard
- ☁️ Files stored permanently on Cloudinary
- Supports images, videos, PDFs and more

## ☁️ Cloud Concept Learned
> Cloud storage — uploading and retrieving files from a managed cloud storage service via a serverless backend.

## How It Works
1. Select or drag & drop a file
2. Click "Upload to Cloud"
3. The frontend sends the file to a Netlify Function
4. The function uploads it to Cloudinary
5. A shareable URL is returned and displayed
