# 🌤️ Weather Dashboard

A live weather dashboard that fetches and displays real-time weather data for any city, with animated backgrounds that match the current weather conditions.

## 🚀 Live Site
👉 [View it here](https://athembele-weather-dashboard.netlify.app)

## 🔑 Access Code
`WTC-T8ENJDT7`

## 🛠️ Tech Used
- HTML, CSS, JavaScript (frontend)
- Netlify Functions (serverless backend)
- OpenWeatherMap API (weather data)

## ✨ Features
- 🌧️ Animated rain drops when it's raining
- ☀️ Glowing sun rays when it's clear and sunny
- 🌲 Swaying trees with wind lines when it's windy
- ❄️ Falling snowflakes when it's snowing
- ☁️ Drifting clouds when overcast
- 🌙 Night mode after 7pm
- Search any city worldwide
